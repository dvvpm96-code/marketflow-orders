# Секреты и доступ

Репозиторий предназначен для приватного размещения. Не коммитьте рабочие базы, конфигурацию сервера, API-ключи, SSH-ключи и пароли. Не добавляйте их в issues или логи CI.

По умолчанию сервер слушает loopback. Для удалённого входа используйте HTTPS с корректным сертификатом либо зашифрованный SSH-туннель. Не запускайте dev-сервер как публичный production-сервис.

Данные принадлежат одному владельцу. Многоустройственный вход не означает наличие ролей сотрудников. Доступ к ОС и резервным копиям означает доступ к ключу шифрования: права на эти файлы должны быть ограничены.

Проверки используют синтетические данные и не подтверждают работоспособность реальных API продавца или принтера. Не включайте автоматические внешние операции без отдельной валидации и согласия владельца.
